# GPRO — центр управления разработкой

Внутренний реестр **46** сервисов GPRO. Отдельное статическое веб-приложение, без зависимостей и сборки.

## Запуск
Откройте `index.html` в браузере или опубликуйте папку на Cloudflare Pages / GitHub Pages. Список, фильтры, редактирование карточек и уровней работают без сервера.

## Важное ограничение
Данные сохраняются **локально в браузере**, а не автоматически в GitHub. Для передачи между устройствами или чатами используйте **Экспорт JSON**, затем **Импорт JSON**. Если реестр будет размещён по публичной ссылке, любой сможет открыть его чистую копию у себя в браузере; записи других людей не синхронизируются. Для реального приватного многопользовательского реестра понадобится авторизация.

## Постоянные правила проекта
- Идентификатор — номер №1–46 из исходного списка.
- №42 и №45 отложены до облачного этапа.
- Каждый сервис развивается с уровня 1 до уровня 9; уровень 0 — работа не начата.
- Переход на следующий уровень утверждает владелец проекта.
- Публичные сервисы имеют прямые ссылки, без видимого каталога и переходов друг на друга.
- Реестр — отдельный проект; финансовый симулятор GPRO существует отдельно.
- Первый сервис: №1 «Финансовый рентген».
